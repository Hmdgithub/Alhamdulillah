# GitHub Pages deployment

1. Create a GitHub repository.
2. Upload this entire folder, keeping the `assets/audio` and `assets/video` paths.
3. Add your music as `assets/audio/shukran-allah.mp3`.
4. Add your video as `assets/video/surprise.mp4`.
5. Open the repository's Settings → Pages.
6. Set the deployment source to your `main` branch and root folder `/`.
7. Save and open the GitHub Pages URL.

For a smaller/faster site, compress the video before uploading. Do not publish private/confidential media in a public repository.
